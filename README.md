# Itch Scratched tap

Apps from [Itch Scratched](https://itchscratched.com), for [Homebrew](https://brew.sh).

```sh
brew install --cask itchscratched/tap/polisher
brew install --cask itchscratched/tap/dug
brew install --cask itchscratched/tap/flow
```

| App | What it does |
| --- | --- |
| [Polisher](https://itchscratched.com/polisher/) | Polish and translate selected text in any app |
| [Dug](https://itchscratched.com/dug/) | See where your disk space went and what is safe to remove |
| [Flow](https://itchscratched.com/flow/) | Switch between Claude Code windows and see which agent needs you |

The apps update themselves, so `brew upgrade` leaves them alone; `brew upgrade --greedy` updates them too.
